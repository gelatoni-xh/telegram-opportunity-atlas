# 证据与数据规则

## 证据标签

- **观察到：**在采集时直接出现在公开频道或 bot 简介、公开帖子或公开指标中的信息。
- **推断：**根据观察到的信息得出的合理商业含义，但没有核实为运营者的实际经营情况。
- **未知：**公开数据中看不到的信息；不要用猜测补齐。

报告中关于变现的每项结论都应链接到公开案例，并注明它是观察结果还是推断。订阅人数和帖子浏览量只是某个时点的快照，不能证明活跃用户、转化或收入。Bot 的公开简介通常也无法显示真实使用量。

## 快照字段

| 字段 | 含义 |
|---|---|
| `captured_at` | 搜索结果的采集日期（UTC）。 |
| `type` | 公开 `channel` 或 `bot`。 |
| `title`, `username`, `url` | 公开可见的名称和链接。 |
| `description` | 采集时的公开简介。 |
| `members` | 有返回时记录的频道公开成员数；缺失或为 null 表示不可用。 |
| `recent_posts` | 抽查的近期频道帖子数量。 |
| `latest_post_date` | 返回结果中最新帖子的日期。 |
| `median_recent_views` | 有数据时记录的抽查帖子公开浏览量中位数。 |
| `matched_queries` | 搜索到该结果的搜索词。 |

派生目录在原始字段之外增加 `areas`。它来自公开的搜索词到覆盖领域映射，方便筛选，不代表对项目业务的人工确认；原始快照仍是证据来源。

快照省略数字 Telegram ID。不要加入私密群组数据、用户标识、私人消息、登录凭据或会话文件。

## 限制

Telegram 公开搜索按相关性排序，并受语言影响。搜索结果数量不代表市场规模。结果可能过时、标注不准、重复，或只是命中关键词。浏览量会受帖子年龄和频道形式影响。当前快照按公开 URL 去重，领域标签保存在派生目录中。单个频道的证据不能证明整个领域的商业状况。

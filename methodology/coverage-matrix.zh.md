# 研究覆盖矩阵

这是本仓库公开样本的覆盖范围。

范围聚焦于个人可以测试的自助式消费者产品和受众型业务。需要销售流程的 B2B 产品不进入主要候选，但如果它影响某一领域可能的商业模式，会在报告中记录。

| 机会领域 | 搜索词 | 快照状态 | 纳入原因 |
|---|---|---|---|
| 购物优惠与优惠券 | `coupon deals`, `discount alert bot`, `food deals`, `restaurant deals`, `grocery deals` | 已采样 | 可直接观察联盟转化路径；消费者价值容易解释。 |
| 返现与价格提醒 | `SaaS deals`, `software discounts`, `cashback deals`, `price tracker bot`, `shopping assistant bot` | 已采样 | 可能支持联盟收入；消费者购买意图仍需验证。 |
| 求职与职业发现 | `job alerts`, `remote jobs`, `remote developer jobs`, `freelance jobs`, `micro jobs`, `remote internships`, `job application bot`, 中文求职词 | 已采样 | 需求明确且重复出现；许多可见模式依赖企业发布岗位或招聘销售。 |
| 奖学金与助学金 | `scholarship alerts`, `scholarship bot`, 中文奖学金词 | 已采样 | 信息价值高；面向消费者收费和重复使用仍待验证。 |
| 语言学习与考试 | `English learning bot`, `IELTS bot`, `language exchange`, `language learning bot`, `exam prep bot`, `online course deals` | 已采样 | 习惯养成可能支持高级工具或学习产品。 |
| AI 与软件发现 | `AI tools bot`, `AI for designers`, `AI productivity tools`, `SaaS deals`, `software discounts` | 已采样 | 需求变化快，可能存在联盟路径；竞争风险高。 |
| 旅行与交通优惠 | `flight deals`, `travel alert bot`, `travel itinerary bot`, `hotel deals`, `train deals` | 已采样 | 购买意图可能通过推荐佣金变现；需考虑季节性。 |
| 海外生活、搬迁与签证 | `expat guide`, `visa updates`, `apartment rental`, `housing expats`, `digital nomad community` | 已采样 | 实际需求强；准确性和按地区维护信息的成本较高。 |
| 健身与习惯支持 | `fitness coach bot`, `workout bot`, `wellness habit tracker`, `meditation bot`, `sleep tracker bot` | 已采样 | 可能产生重复互动；健康声明和留存需要谨慎处理。 |
| 游戏 | `gaming alerts`, `game deals` | 已采样 | 消费者受众可能较大；变现和平台依赖程度差异明显。 |
| 创作者工具与发布 | `creator tools bot`, `content creator community`, `creator monetization`, `newsletter tools` | 已采样 | 能观察到创作者需求，但部分模式会转向向创作者销售服务。 |
| 加密货币与交易信息 | `crypto signals`, `crypto alerts bot` | 已采样，高风险 | 存在可见活动，但信任、监管和财务损失风险使其不适合作为默认优先方向。 |
| 本地活动与城市发现 | `local events`, `event discovery bot`, `city guide` | 已采样 | 可能有用且可本地化；信息密度和新鲜度未知。 |
| 餐饮、杂货与餐厅优惠 | `food deals`, `restaurant deals`, `grocery deals`, `recipe channel` | 已采样 | 消费决策频繁，可能有联盟或优惠路径；本地供给未知。 |
| 家庭、育儿与膳食计划 | `parenting community`, `parenting tips channel`, `meal planning bot` | 已采样 | 重复任务可能支持工具或付费内容；如何触达受众未知。 |
| 个人预算与支出工具 | `budget planner bot`, `expense tracker bot`, `personal finance bot` | 已采样 | 工具价值明确，但信任和付费意愿未经验证。 |
| 效率与个人组织 | `productivity bot`, `study planner bot` | 已采样 | 适合 bot 形态；市场拥挤，留存仍未知。 |
| 书籍、媒体与娱乐发现 | `book summaries`, `reading club` | 已采样 | 适合频道形态；版权和变现需要单独评估。 |
| 人身安全与紧急协助 | `personal safety bot` | 已采样 | 对消费者有用，但信任、可靠性和误报处理是关键。 |

## 覆盖说明

每个领域尽可能搜索至少两个意图词；平台有结果时，频道和 bot 都要纳入；记录搜索日期和语言，并抽样查看公开指标。仅仅搜到关键词结果，不代表该领域已经验证。各领域样本深度和语言覆盖仍不均衡，Telegram 也未被穷尽索引。

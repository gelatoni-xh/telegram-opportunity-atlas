# Telegram 机会图谱：独立开发者的 19 个产品方向研究

[![中文](https://img.shields.io/badge/阅读中文-README.md-1677ff?style=flat-square)](README.md) [![English](https://img.shields.io/badge/Read%20English-README.en.md-555?style=flat-square)](README.en.md) [![数据日期](https://img.shields.io/badge/数据日期-2026--11--03-0a7?style=flat-square)](reports/2026-11-consumer-opportunity-scan.zh.md) [![License](https://img.shields.io/badge/代码-MIT-555?style=flat-square)](LICENSE)

基于 **492 条公开频道与 Bot 记录、68 个搜索词**，比较 19 个消费者领域的现有供给、可观察的商业信号和待验证问题，帮助独立开发者开展选题与竞品调研。

**[浏览公开样本](catalog/README.zh.md) · [下载 CSV](data/catalog-2026-11-03.csv) · [比较五个产品领域](reports/2026-11-five-area-comparison.zh.md) · [阅读频道内容选品指南](reports/2026-11-channel-content-selection-observation.zh.md)**

## 如何使用这份图谱

| 你想做什么 | 从哪里开始 |
|---|---|
| 找一个值得调研的产品方向 | 浏览下方的 **19 个领域总览**，对照用户任务、现有供给和待验证问题，选出与你的经验和资源匹配的方向。 |
| 查找某个领域已有的频道和 Bot | 打开[按领域浏览的样本目录](catalog/README.zh.md)，查看项目名称、公开链接和命中搜索词；需要自行筛选时可[下载 CSV](data/catalog-2026-11-03.csv)。 |
| 深入比较候选方向 | 阅读[五个领域比较](reports/2026-11-five-area-comparison.zh.md)，再参考[求职与旅行核验](reports/2026-11-jobs-travel-validation.zh.md)，了解案例、比较口径和仍需核验的问题。 |
| 扩展自己的调研 | 参考[覆盖矩阵与搜索词](methodology/coverage-matrix.zh.md)、[证据与字段说明](methodology/evidence-and-data.zh.md)，再按下方的命令执行搜索。 |

选定方向后，可按“用户要完成什么任务 → 已有哪些供给 → 有哪些公开证据 → 还需要验证什么”的顺序整理自己的调研记录。

## 19 个领域，一页总览

判断表示本轮研究优先级。**优先验证不等于已证明能赚钱**；样本按关键词发现，不代表市场规模。同一记录可能命中多个领域，括号内为频道 / Bot 数。

| 领域 | 样本（频道 / bot） | 判断 | 核心结论 |
|---|---:|---|---|
| 购物优惠与优惠券 | 19（5 / 14） | <strong>优先验证</strong> | 有联盟披露和购买意图；缺点击、转化和收入数据。 |
| 求职与职业发现 | 61（36 / 25） | <strong>优先验证</strong> | 任务高频、受众信号较强；需确认是否依赖雇主销售。 |
| 奖学金与助学金 | 21（10 / 11） | <strong>优先验证</strong> | 提醒和筛选价值明确；准确性、地区覆盖和付费路径未验证。 |
| AI 与软件发现 | 38（22 / 16） | <strong>优先验证</strong> | 购买意图可能较强；需验证推荐透明度、更新成本和竞争。 |
| 旅行与交通优惠 | 40（13 / 27） | <strong>优先验证</strong> | 交易价值可能较高；需验证数据源、地区覆盖和推荐收入。 |
| 语言学习与考试 | 48（4 / 44） | <strong>保留观察</strong> | bot 供给多；实际使用量、效果和付费意愿未知。 |
| 海外生活、搬迁与签证 | 17（10 / 7） | <strong>保留观察</strong> | 需求具体；地区差异和信息维护成本高。 |
| 返现与价格提醒 | 27（7 / 20） | <strong>保留观察</strong> | 任务适合自动化；需可靠价格源和转化证据。 |
| 餐饮、杂货与餐厅优惠 | 34（24 / 10） | <strong>保留观察</strong> | 消费频率高；本地供给限制复制。 |
| 本地活动与城市发现 | 14（6 / 8） | <strong>保留观察</strong> | 本地需求可能真实；内容源和更新成本未明。 |
| 个人预算与支出工具 | 30（0 / 30） | <strong>保留观察</strong> | bot 形态匹配；信任、隐私和留存证据不足。 |
| 效率与个人组织 | 20（0 / 20） | <strong>保留观察</strong> | 原型门槛低；市场拥挤且长期使用未知。 |
| 创作者工具与发布 | 18（6 / 12） | <strong>保留观察</strong> | 任务明确；许多模式实际面向创作者销售服务。 |
| 游戏 | 18（10 / 8） | <strong>保留观察</strong> | 受众可能大；平台、版权和地区依赖较强。 |
| 书籍、媒体与娱乐发现 | 18（10 / 8） | <strong>保留观察</strong> | 频道形态自然；版权、生产和付费意愿需核查。 |
| 家庭、育儿与膳食计划 | 11（4 / 7） | <strong>暂不推荐</strong> | 样本小、责任高；重复使用和变现证据弱。 |
| 健身与习惯支持 | 39（0 / 39） | <strong>暂不推荐</strong> | 健康责任高；效果、活跃度和安全边界未知。 |
| 人身安全与紧急协助 | 3（0 / 3） | <strong>暂不推荐</strong> | 样本极少且容错低；可靠性证据不足。 |
| 加密货币与交易信息 | 18（2 / 16） | <strong>暂不推荐</strong> | 金融和监管风险高；信号质量无法由公开指标证明。 |

## 这批数据的范围

2026-11-03 的快照有 492 条记录，来自 68 个搜索词，覆盖 19 个消费者领域：169 个频道、323 个 bot。其中 491 条有公开 Telegram 链接，另 1 条结果没有公开用户名或链接。这是按关键词发现的样本，不代表 Telegram 的整体分布。

## 重新执行搜索

搜索脚本基于 Telegram 官方 API/TDLib 接口。运行前需要安装 TDLib，并准备 [Telegram API 应用](https://my.telegram.org/apps)：

```sh
python3 scripts/search_public.py "food deals" "local events" --output data/new-scan.jsonl
```

首次运行时，脚本会在本地终端提示输入 API 凭据和 Telegram 登录信息；API hash 使用隐藏输入。登录会话保存在仓库之外的本地目录。不要把凭据或登录码写入仓库或聊天记录。搜索结果是公开供给样本，不代表用户规模、留存或收入。更多字段说明见[证据与数据说明](methodology/evidence-and-data.zh.md)。

## 文件导航

- `reports/`：按日期保存的调研报告，中英文各一份。
- `methodology/`：覆盖范围、证据标准和数据字段说明，中英文各一份。
- `data/`：去重后的公开搜索快照；简介等原始内容保留采集时的语言。
- `data/catalog-2026-11-03.jsonl`：由原始快照派生的领域标注目录；`areas` 只根据 `matched_queries` 映射，不改变原始证据。
- `data/representative-validation-2026-11-03.json`：对少量代表项目的公开资料核验，包含日期、观察字段和明确未知项。
- `scripts/`：用于重复公开搜索、生成目录和校验数据的脚本。
- `CHANGELOG.md`、`CONTRIBUTING.md`：版本变化和提交证据的规则。

中英文版本分开保存。更新结论、数字、范围或方法时，请同步修改对应的两份文档。Telegram 名称、链接和搜索词保留原文，方便读者自行核对。

本地校验：

```sh
python3 scripts/validate_snapshot.py data/snapshot-2026-11-03.jsonl \
  --derived data/catalog-2026-11-03.jsonl
```

此快照的预期输出：

```text
OK: 492 records (169 channels, 323 bots)
```
